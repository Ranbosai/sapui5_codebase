# AuroraStream Mobile

React Native app powered by Expo serving as the mobile companion to the AuroraStream HD video platform.

## Getting Started

```bash
npm install
npm run start --workspace mobile-app
```

Use the Expo Go app or an emulator to preview the mobile experience.

## Features
- Shared design language with the web experience
- Placeholder home screen for playlists and chat modules
- Ready for integration with authentication and GraphQL APIs
